# Gestión de Datos de Países en Python

video explicativo: https://youtu.be/GxgqfaKnYi8 

## 1. Descripción del proyecto

Este proyecto consiste en desarrollar un programa en Python para gestionar información de diferentes países mediante un archivo CSV.

El programa permite cargar, consultar, filtrar, ordenar y analizar datos de países, utilizando conceptos de programación aprendidos durante la cursada.

## 2. Objetivos

- Practicar el uso del lenguaje Python.
- Trabajar con archivos CSV para almacenar y leer información.
- Utilizar funciones para organizar el código.
- Aplicar estructuras condicionales y repetitivas.
- Realizar búsquedas, filtros, ordenamientos y cálculos estadísticos.
- Presentar los resultados mediante un menú interactivo.

## 3. Archivos del proyecto

- `main.py`: contiene el programa principal y el menú de opciones.
- `funciones.py`: contiene las funciones utilizadas para procesar y gestionar los datos.
- `paises.csv`: almacena la información de los países.

## 4. Datos utilizados

El archivo CSV contiene información de los países, incluyendo los siguientes campos:

- Nombre del país.
- Población.
- Superficie.
- Continente.

## 5. Funcionalidades

El programa ofrece distintas opciones para trabajar con los datos, entre ellas:

- Consultar información de países.
- Aplicar filtros y búsquedas.
- Ordenar los datos según distintos criterios.
- Calcular estadísticas de población y superficie.
- Contabilizar países por continente.
- Guardar los datos en un archivo CSV.

Las opciones se encuentran organizadas en un menú interactivo.

## 6. Tecnologías utilizadas

- Python 3.
- Visual Studio Code.
- Archivos CSV.

## 7. Cómo ejecutar el programa

1. Instalar Python 3.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Verificar que los archivos `main.py`, `funciones.py` y `paises.csv` se encuentren en la misma carpeta.
4. Ejecutar el archivo `main.py`.
5. Seguir las instrucciones que aparecen en la consola y seleccionar las opciones del menú.

## 8. Resultados

El programa permite obtener información estadística de los países cargados. Entre los resultados se incluyen el país con mayor población, el país con menor población, el promedio de población, el promedio de superficie y la cantidad de países por continente.

## 9. Conclusión

La realización de este proyecto permitió aplicar conocimientos de programación en Python, organizar un programa mediante funciones y trabajar con archivos CSV.

Además, permitió practicar el procesamiento de datos, la resolución de problemas y la presentación de resultados a través de un menú interactivo.
